# Drive Clone

A Google Drive-inspired cloud storage application built using Node.js, Express.js, MongoDB, and Firebase Storage.

## Features

- User Authentication using JWT
- Password Encryption using bcrypt
- File Uploads
- File Downloads
- Firebase Storage Integration
- MongoDB Integration

## Tech Stack

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Cloud Storage
- Firebase Storage
- Firebase Admin SDK

### Authentication & Security
- JWT (jsonwebtoken)
- bcrypt

### Middleware & Utilities
- Multer
- Multer Firebase Storage
- Cookie Parser
- dotenv
- express-validator

### Template Engine
- EJS
